عناصر التفاعل

Proposed These are static visual specifications, not production components. Nothing here submits or stores data. Press Tab to see the real focus ring. Hover, focus and loading states are also pinned below for review.

الأزرار

hover (pinned)إرسال focus-visible (pinned)إرسال loading

Every button is at least 44 × 44 CSS px. Loading keeps the button's width, changes the label, and sets aria-busy. There is no spinning animation here.

الحركة

Proposed The only motion on this sheet is colour and border transitions (120ms) on hover. With prefers-reduced-motion: reduce, the token file sets every duration to 0ms. There is no continuous decorative animation and no logo motion.
